# Kino Sayt Media

Image and video assets for the Kino Sayt project.

## What is in this repo

This repo stores only static media files. It has no application code.

```
images/   # movie posters, banners and short video clips
```

## How to use

Link the files directly from a web page, for example:

```html
<img src="images/CoverBanner.jpg" alt="Cover">
<video src="images/Avatar2.mp4" controls></video>
```

## Notes

- Files are large. This repo is not meant for code.
- The app code lives in the main movie site repo.
