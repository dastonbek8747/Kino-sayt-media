# 🖼 Kino-sayt Media

**Kino-sayt** loyihasi uchun media (rasm) fayllari ombori.

---

## ✨ Mazmun

- 🎬 Kino va serial afishalari (`.webp`, `.jpg`, `.jfif`)
- 📁 `images/` papkasida saqlanadi

Bu **media ombori** — kod o'z ichiga olmaydi. Rasmlar asosiy loyiha ([Kino-sayt](https://github.com/dastonbek8747/Kino-sayt)) tomonidan ishlatiladi.
